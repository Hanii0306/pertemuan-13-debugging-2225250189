## Deskripsi
Pertemuan ini membahas proses debugging, tracing, testing,
dan penyusunan test case menggunakan Python.

Debugging merupakan proses mencari dan memperbaiki kesalahan
pada program. Tracing digunakan untuk menelusuri perubahan
nilai variabel dan alur eksekusi program.

Testing dilakukan untuk memastikan hasil program sesuai
dengan hasil yang diharapkan.

## Tujuan Pembelajaran
1. Membedakan syntax error, runtime error, dan logical error.
2. Melakukan tracing nilai variabel.
3. Menggunakan breakpoint pada VS Code.
4. Membuat test case normal, batas, kosong, dan tidak valid.
5. Membandingkan expected result dengan actual result.
6. Mengidentifikasi dan memperbaiki bug.
7. Melakukan pengujian ulang setelah perbaikan.

## Struktur Folder
- kasus: Berisi program yang sengaja dibuat memiliki bug.
- latihan: Berisi latihan tracing dan testing.
- praktik: Berisi praktik debugging secara menyeluruh.

## Cara Menjalankan
Jalankan program melalui terminal VS Code.

Contoh:
python kasus/kasus_01_batas_kelulusan.py

Untuk latihan:
python latihan/01_trace_loop.py

Untuk praktik:
python praktik/praktik_4_debugging.py

## Teknik Debugging
1. Mengamati gejala kesalahan.
2. Membuat test case.
3. Membandingkan hasil aktual dan hasil yang diharapkan.
4. Menelusuri kode menggunakan tracing atau breakpoint.
5. Menemukan akar penyebab bug.
6. Memperbaiki kode.
7. Menjalankan pengujian ulang.
